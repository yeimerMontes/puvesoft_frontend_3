# Customer Flow

## List customers
- GET `/clientes?page={page}&search={search}&size={size}&paginate={paginate}`

## Create customer
- POST `/clientes`

## Update customer
- PUT `/clientes/{id}`

## Delete customer
- DELETE `/clientes/{id}`

## Search by name
- GET `/buscarCliente?search={search}`

## Search by document
- GET `/buscarClienteDocumento?search={search}`
