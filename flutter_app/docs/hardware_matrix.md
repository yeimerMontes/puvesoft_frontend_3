# Hardware Matrix

## Printers
- Fiscal printers: vendor SDK integration (Android/iOS/Windows)
- ESC/POS fallback: only where fiscal rules allow

## Scanners
- USB HID: desktop/Windows + Android OTG
- Bluetooth: Android/iOS
- Camera: Flutter camera + barcode/QR plugin

## Notes
- Device-specific drivers are required on Windows.
- Bluetooth printers/scanners may need pairing UX.
